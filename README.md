# Avatar Content Engine

数字人 IP 内容引擎：先验证可持续复用的角色与声音，再将人物口播和自己的实拍素材组合成完整内容。

当前处于规划与验证阶段，尚未实现应用、接入真实账号或完成角色测试。默认路线为单用户、本地 CPU、FastAPI 工作台与云端生成 API，无独立 GPU 也可启动项目。

## 实施顺序

1. **阶段 A：角色与 API 验证。** 确定一种内容方向，准备主形象与声音，核查账号、额度和试验上限，完成短样片及跨日复测。
2. **阶段 B：最小可用版。** 一个角色、一种外观、一套声音、一家视频服务，完成一条实拍混剪；从首次调用起记录提交状态、费用与下载结果。
3. **阶段 C：可靠生产版。** 补齐任务调度、恢复、预算对账与备份，通过连续三条同方向作品和故障演练后再启用小批量。
4. **阶段 D：按需扩展。** 增加脚本助手、参考视频分析、更多模板、外观和供应商。

各阶段以规划文档中的 G0–G4 门槛验收，不以页面数量或单次生成成功代替效果验证。
